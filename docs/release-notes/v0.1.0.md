First test release. It shows the heatmap for a single document, and includes the testing tools for the first round of checks against real Google Docs history.

**Install:** download `writing-heatmap-extension-v0.1.0.zip` below, unzip it, then go to `chrome://extensions` → turn on Developer mode → **Load unpacked** → choose the unzipped folder. Full steps are in the [README](https://github.com/softwareconvene/writingheatmap#install-from-github).

- A heatmap over the finished document with six categories: composed in place, lightly revised, heavily revised, large insertion, history unclear, mixed.
- Click a passage to see its exact edits, or replay just that passage.
- A summary card, a timeline of writing sessions, a student view, and a printable report with your notes.
- Everything runs in your browser. Nothing is sent anywhere.
- Testing tools (Settings): a feasibility check and a raw history download, for test documents only.

Google's history format is undocumented, so this release is for testing. Expect the categories to be tuned after the first test documents.
