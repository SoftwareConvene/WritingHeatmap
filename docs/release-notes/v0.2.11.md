**Checking headings on a real Doc**
- Some Docs that use Heading 1–6 still show no headings in Writing Heatmap, which means Google records headings differently from what the extension expects.
- **Settings → Show testing tools**, then open the **Testing** card at the bottom of the side panel. A new **Style codes seen** table lists the style codes Google sent for that Doc and a few of their values (numbers and short codes only, never text), plus how many paragraphs were read as headings.
- A screenshot of that table from a Doc that uses headings is enough to fix the heading reading.
