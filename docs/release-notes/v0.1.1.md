Fixes installing from the zip: `manifest.json` is now at the top of the zip, so the unzipped folder loads directly with **Load unpacked** (on Windows, "Extract All" used to add a second folder level, and Chrome then said "Manifest file is missing or unreadable").

**Install:** download `writing-heatmap-extension-v0.1.1.zip` below (not "Source code"), unzip it, go to `chrome://extensions`, turn on Developer mode, click **Load unpacked**, and choose the folder that has `manifest.json` directly inside it.

Everything else is the same as [v0.1.0](https://github.com/softwareconvene/writingheatmap/releases/tag/v0.1.0).
