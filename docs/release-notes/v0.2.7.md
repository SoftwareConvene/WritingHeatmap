**Update:** download `writing-heatmap-extension-v0.2.7.zip` below, replace your old folder, and press the reload arrow on the extension's card at `chrome://extensions`.

**Sections are the Doc's headings**
- Checkpoints, **Jump to section**, the per-student pages and the class dashboard now use only the paragraphs styled **Heading 1–6**, the same ones a Google Docs table of contents lists. Template lines like "Hypothesis:" or "Question 2:" are no longer sections on their own, so the list stays short.
- The Title and Subtitle are not sections.
- If a student types on a heading's line from the template, that heading keeps its template name, so their copy still lines up with everyone else's.
- No headings in the Doc? Checkpoints show whole-document totals. To split them up, style each section title as a heading (**Format → Paragraph styles**) in the template before copying it to students.
