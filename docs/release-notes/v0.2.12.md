**Update:** download `writing-heatmap-extension-v0.2.12.zip` below, replace your old folder, and press the reload arrow on the extension's card at `chrome://extensions`. If a document was open in the viewer, press **Refresh** once so its headings are read again.

**Headings, as in the table of contents**
- Headings are now read from Google's own HTML copy of each Doc, which marks Heading 1–6 exactly as the table of contents does. Docs that use headings get only those as sections again, not every template line.
- A Heading 1 section now includes the Heading 2s under it, so a section shows everything up to the next heading at its level.
- Viewing an earlier moment (the "Document as of" slider, checkpoints) finds the same headings even if their text has changed since.

**Class dashboard**
- **Same section in every document:** tick several sections to read them together in each student's document.
- **Checkpoints:** click any number to open that student's document at that section, as it stood at that checkpoint. **See in every document** under a checkpoint shows the chosen section from every student's document as it stood then, with a **Back to now** link.
- Before **Analyse all**, the checkpoint section list now says to press it.

**Share with a co-teacher**
- **Share class pack** (top of the dashboard) saves your dashboards in one file: names, student labels, Doc links, due dates, checkpoints, review marks, and optionally editor roles and school hours.
- Your co-teacher presses **Import class pack** and picks the file. A preview shows what it adds. Send a new pack when something changes: importing it again updates their dashboards, combines checkpoints and keeps review marks they set themselves.
- The pack never contains student writing. Their copy of Writing Heatmap reads the Docs with their own sign-in, so they need edit access too. Share the file the way you would share a class roster.
