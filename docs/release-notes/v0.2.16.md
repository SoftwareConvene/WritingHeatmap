**A draft copied into the final section is not "copy/paste"**
- When a student copies their own text from elsewhere in the same Doc (for example a rough draft pasted into the final-draft section), Writing Heatmap recognises it. That text keeps the colour of how it was first written, then shows any edits made after the copy. It is **not** red.
- A **⧉** marks where copied text starts, and the colour key explains it.
- It is counted on its own everywhere: **Copied within the Doc** on the Compare students tab, a ⧉ line on the student's card in the side panel, and a **Copied within Doc** column in the class dashboard and its CSV. It no longer counts as a large chunk or shows as a red mark on the timeline.
- Copying between the Doc's tabs is recognised too.
- To be recognised, the pasted text must match 40 or more characters that are in the same Doc at the moment of pasting. Text pasted from a different Doc or file still counts as a large insertion, because Google's history does not say where a paste came from.
